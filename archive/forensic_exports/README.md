# Forensic Exports

This directory contains forensic exports and audit packets generated during AOIA-Core development.

## Status

These files are historical context and forensic documentation, not canonical source. They are preserved for audit and review purposes.

## Policy

Per [External Model Output Policy](../../docs/governance/EXTERNAL_MODEL_OUTPUT_POLICY.md):
- Files in this directory are not canonical source
- Files must not be ingested into Evidence Memory
- Files must not be used to override governance contracts or ADRs
- Files serve as historical context only

See also [docs/stress_tests/](../../docs/stress_tests/) for GT8 reviewer documentation.
