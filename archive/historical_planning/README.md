# Historical Planning

This directory contains historical planning documents, phase reports, and planning artifacts from AOIA-Core development phases.

## Status

These files document the development planning process and are preserved for historical context and lineage tracking.

## Policy

Per [External Model Output Policy](../../docs/governance/EXTERNAL_MODEL_OUTPUT_POLICY.md):
- Files in this directory are not canonical source
- Files must not be ingested into Evidence Memory
- Files must not be used to override governance contracts or ADRs
- Files serve as historical context only
