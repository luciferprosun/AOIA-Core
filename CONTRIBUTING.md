# Contributing

AOIA-Core is a safety-sensitive repository. Changes should stay small, reviewable, and explicitly scoped.

- Prefer small commits that isolate one reviewable concern.
- Do not expand command execution behavior without explicit review.
- Do not introduce new child-process or shell execution pathways.
- Run tests before merge or commit.
- Documentation must clearly distinguish implemented, partial, and planned states.
- Legacy or transitional areas must be labeled so reviewers can separate current claims from older repository contents.
