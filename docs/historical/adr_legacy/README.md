# Architecture Decision Records

This directory stores Architecture Decision Records for the terminal app and
AOIA expansion.

## Format

Each ADR should include:

- title
- status
- date
- context
- decision
- consequences
- validation

## Status Values

- `proposed`
- `accepted`
- `superseded`
- `rejected`

## Naming

Use:

```text
NNNN-short-title.md
```

Example:

```text
0001-keep-aoia-isolated.md
```
