# Chat4 Reviewer Wording Guide

Date: 2026-06-07

Phase: C4-A docs-only agentic readiness policy.

## Purpose

This guide helps reviewers avoid wording that overclaims autonomy, source verification, production readiness, or uncontrolled repository authority.

## Unsafe Wording

The following phrases are unsafe wording examples and should not be used as project claims:

- autonomous software factory
- AI workers build the app
- Gemini updates the repo
- bots add knowledge automatically
- bot-verified sources
- self-improving agent
- automatic canonicalization
- AI team replaces humans
- Gemini browses and updates the knowledge base
- production-ready agent
- safe autonomous browser

## Why This Wording Is Unsafe

These phrases imply uncontrolled autonomy, direct repository writes, automatic source trust, direct browser action, or replacement of human review.

AOIA-Core / AIOA WhiteHat does not claim those capabilities or goals.

## Safe Alternatives

Use wording that preserves human authority and proposal boundaries:

- human-led proposal workflow
- controlled helper model review
- candidate knowledge generation
- source-aware draft proposal
- human approval boundary
- reviewer-auditable back-polishing loop
- not autonomous
- not canonical without review
- not production-ready
- model-assisted source candidate discovery
- proposal only, not action
- model proposes, human decides

## Reviewer Rule

When wording suggests the model can act directly, rewrite it so the model can only propose and a human reviewer decides.

When wording suggests source verification, rewrite it so verification remains human-reviewed and provenance-bound.

When wording suggests production readiness, rewrite it as a future policy or review boundary unless separately validated.
