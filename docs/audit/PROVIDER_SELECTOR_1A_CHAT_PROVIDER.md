# Provider Selector 1A: Chat Provider Metadata

Provider Selector 1A records one validated chat provider identifier as deterministic,
immutable metadata. Known identifiers are `openai_chat`, `anthropic_chat`,
`google_gemini_chat`, `local_ollama_chat`, and `mock_chat`.

Selection does not enable or contact a provider, load credentials, grant authority,
satisfy approval gates, permit execution, or permit artifact writes.
