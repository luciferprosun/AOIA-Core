# AOIA/NMS Reviewer Glossary

This glossary defines the project terms used in the reviewer and grant-facing
documentation. It is intentionally conservative: terms here do not promote
external research material into AOIA-Core runtime authority.

## AOIA-Core

AOIA-Core is the local-first runtime and engineering prototype. It focuses on
AI-assisted technical workflows where evidence, provenance, contradictions,
memory traces, runtime state, model output, and human-approved execution need
clear boundaries.

## AIOA / AOIA

AIOA / AOIA is the broader project naming and conceptual frame around adaptive
oceanic intelligence architecture. In this repository, AOIA is used narrowly for
deterministic routing, local-first execution, evidence boundaries, and
operator-controlled workflows.

## AOIA-NMS / NMS

AOIA-NMS / NMS is the grant-facing documentation and methodology layer for
AOIA-Core. It is not a separate runtime. It explains the review method,
stress-test framing, roadmap, and scope boundaries for funders and reviewers.

## MHLM

MHLM means Multiple Hallucination Language Model. It is a problem-framing concept
for the risk that several models may repeat or reinforce unsupported claims.

## MDLH

MDLH means Multiple Distributed Language Hallucination. It describes the broader
risk that hallucinated or weakly supported claims can become distributed across
multiple tools, reports, prompts, and model outputs.

## LSC

LSC is the historical research origin and a high-claim-density neutrino archive
stress-test corpus only. It is used to test whether AOIA/NMS can separate claims,
provenance, contradictions, and evidence status. LSC is not validated physics and
is not AOIA-Core scientific output.

## SCEMDA

SCEMDA is external applied or methodological context. It is non-canonical for
AOIA-Core and is not AOIA-Core runtime authority.

## HNC

HNC is external research or applied context associated with non-canonical
materials. It is not evidence for AOIA-Core and is not part of runtime authority.

## Gary / external collaborator material

Gary-related and other external collaborator material may be historical,
methodological, or applied context. It remains external and non-canonical unless
explicitly reviewed and promoted through governed human-approved processes.

## Evidence Memory

Evidence Memory is the governed evidence layer. Runtime output, logs, model
responses, and reasoning traces do not become evidence automatically.

## Reasoning Memory

Reasoning Memory records reasoning traces or operational context. It can support
review, but it is not the same as evidence.

## Provenance

Provenance records where an artifact, claim, action, or evidence-like item came
from and how it was handled. Provenance supports auditability; it does not by
itself prove truth.

## Contradiction Registry

The Contradiction Registry tracks conflicts, unresolved claims, and review
status so disagreement is visible instead of silently collapsed into certainty.

## Deterministic / rule-based retrieval

Deterministic or rule-based retrieval means local, repeatable retrieval behavior
that does not depend on model consensus as proof. It is used to keep routing and
evidence boundaries inspectable.

## Stress-test corpus

A stress-test corpus is difficult source material used to test the review
method. It is not automatically endorsed, validated, or promoted into runtime
authority.

## Runtime authority

Runtime authority is the set of source code, governance rules, tests, and
approved repository documents that define AOIA-Core behavior. External reports,
model outputs, and research archives are not runtime authority by default.

## External model output

External model output is historical or reference context unless explicitly
promoted through governed human-approved processes. Model agreement is not
evidence by itself.
