# Python Knowledge Library Scaffold

## Purpose

This library will collect verified, human-reviewable Python advisory and correction records for AIOA Whitehat.

## Scope

- Python basics
- CLI automation
- safe file handling
- subprocess safety
- virtual environments
- package installation
- testing
- JSON/JSONL handling
- Linux/RHCSA automation support

## Non-Goals

- not a full Python course
- not runtime execution
- not autonomous coding
- not a replacement for human review
- not connected to AOIA runtime yet

## Review Model

Every future entry should include:

- problem
- unsafe or incorrect pattern
- corrected pattern
- explanation
- safety notes
- verification steps
- review status

## Current Status

Scaffold only. Entries are examples and require human review before promotion.
